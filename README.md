# JASS Portrait Prompt Studio v1.2

Offline PySide6 visual workspace for detailed portrait-prompt creation.

## Features
- Visual Workspace
- Local photo import and large preview
- 100 detailed prompts
- Prompt Builder with mood, expression, lighting, environment, styling, camera, composition, angle and depth controls
- Four-level allure intensity
- Face/identity preservation
- Maximum photographic detail
- Negative prompt
- Surprise Me generator
- Favorites, search and category filtering
- Local prompt history with associated photo path
- TXT export
- Copy Prompt / Copy Both
- No cloud/API dependency

## Run

```bash
pip install PySide6
python JASS_Portrait_Prompt_Studio_v1_2_final.py
```

History is stored locally at:

```text
~/.jass_portrait_prompt_history.json
```

The imported image is displayed locally and is not uploaded by this application.
